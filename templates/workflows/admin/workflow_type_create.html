{% lucide "circle-help" class="w-5 h-5" %} Template Creation Help

Before creating a template:

  • • Ensure you have selected the appropriate owner group
  • • Choose roles that should have permission to create workflows
  • • Provide a clear description for template identification
  • • Add optional fields for custom workflow data collection

Optional Fields:

  • • Text/Long Text: For short or extended text input
  • • Number: For numeric values (integers/decimals)
  • • Date/DateTime: For date and time selection
  • • Email/URL: For email addresses and web links
  • • Dropdown/Radio: For predefined option selection
  • • Checkbox: For true/false or yes/no options

After creation, you can configure states, transitions, and additional workflow settings. The optional fields will be available when users create new workflows of this type.
