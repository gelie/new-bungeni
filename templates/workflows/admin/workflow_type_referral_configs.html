{% lucide "circle-help" class="w-4 h-4" %} How referrals work

  • When a workflow is referred to a group, all members of that group can view the workflow.
  • Transition roles: members of the referred group with these roles can perform transitions (in addition to the owning group).
  • Edit roles: members of the referred group with these roles can edit the workflow fields.
  • If no transition roles are set, referred group members cannot perform any transitions.
  • Referrals are tracked with full history. Only one referral can be active at a time.
